## This is a project created in 2023 with Thomas Kaleta
We have not used any AI models all code was written manually


Main purpose of this project was to experiment with **procedural mesh generation** for **heightmap vertex offsetting**


https://github.com/user-attachments/assets/4b014c90-e053-4170-8257-a016ed15fab9

### Project overview

Procedurally generated sphere with adjustable resolution depending on quality settings or manual override
